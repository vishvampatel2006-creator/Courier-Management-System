# 📦 Courier & Parcel Delivery Tracker

An interactive, console-based **Java application** designed to streamline courier tracking and parcel management. This project demonstrates core software engineering principles including Object-Oriented Programming (OOP), Java Collections Framework, File I/O for persistent storage, and robust Exception Handling.

---

## 🚀 Key Features
- **Parcel Registration:** Add new courier details including tracking ID, sender/receiver info, and delivery status.
- **Real-Time Tracking:** Search and view the current status of any parcel using its unique ID.
- **Status Updates:** Modify delivery statuses (e.g., Booked, In-Transit, Delivered).
- **Persistent Data Storage:** Uses Java File I/O to save and load parcel records so data is never lost when the program closes.
- **Error Handling:** Custom exception handling for invalid inputs and missing records.

---

## 🛠️ Tech Stack & Concepts Used
- **Language:** Java
- **Core Concepts:** Object-Oriented Programming (Encapsulation, Abstraction, Modular Classes like `Parcel` and `CourierManager`)
- **Data Structures:** Java Collections Framework (`ArrayList` / `HashMap`)
- **Storage:** Java File Handling (`FileReader`, `FileWriter`, `BufferedReader`)
